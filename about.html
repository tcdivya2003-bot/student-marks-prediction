About This Project

Project Objective

This project demonstrates a core Machine Learning concept using the simplest possible relationship: how the number of hours a student studies relates to the marks they score. It intentionally uses only one input feature so that the underlying ML concept (Linear Regression) can be understood clearly, without distraction from other factors.

Dataset

The dataset used here (dataset/student_marks.csv) is a synthetically generated sample dataset created for educational demonstration purposes. It is not collected from real students. It contains two columns: Study_Hours and Marks, generated to reflect a realistic, mostly-linear relationship with natural variation.

Machine Learning Algorithm

This project uses Linear Regression, a supervised learning algorithm for regression problems. It fits a straight line of the form:

Marks = m × Study_Hours + c

where m is the slope (how much marks increase per additional study hour) and c is the intercept (the baseline marks at zero study hours). Linear Regression is well suited here because both the input and output are numerical, and the relationship between them is expected to be approximately linear.

How Prediction Works

When you submit a number of study hours on the Predict page, the Flask backend loads the already-trained model (it does not retrain on every request), validates your input, and passes it to the model's predict() function to get the expected marks, which is then displayed rounded to two decimal places.

Technologies Used
  • Python 3.11+
  • Pandas, NumPy - data handling
  • Scikit-learn - Linear Regression model
  • Matplotlib - data visualization
  • Flask - backend web framework
  • HTML5, CSS3, JavaScript, Bootstrap - frontend
  • Joblib - model serialization

Note: This tool provides a machine-learning-based estimate only, based purely on study hours. It is not a guaranteed examination result and does not account for other factors that can influence a student's actual performance.
