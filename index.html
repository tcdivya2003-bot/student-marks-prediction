Student Marks Prediction

Based on Study Hours

A simple Machine Learning project that learns the relationship between how many hours a student studies and the marks they are likely to score.

Study Hours → Machine Learning Model → Predicted Marks

Predict Marks

Simple Idea

Students who study more hours generally tend to score higher marks. This project uses that single relationship to build a Machine Learning model.

Linear Regression

A Linear Regression model is trained on historical study-hours-and-marks data to learn the best-fit line: Marks = m × Study Hours + c.

Instant Prediction

Enter any number of study hours and the trained model instantly predicts the expected marks out of 100.
